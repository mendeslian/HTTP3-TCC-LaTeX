\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

HTTP/3 uses QUIC/UDP to reduce latency and improve resilience on poor networks. Node.js does not offer stable native support, so this thesis asks whether HTTP/3 can work in Node.js REST APIs, what obstacles arise, how it performs compared to HTTP/1.1 and HTTP/2, and how to make it work in practice. The work combined published research, a rapid literature review, and experiments with a real API. For these experiments, an API was built for load testing. HTTP/1.1, HTTP/2, and HTTP/3 terminate on the same NGINX reverse proxy, and the same h2load (nghttp2 1.70.0) generates the load for all three. Two sets of tests were run, each with ten rounds and a 60 s plateau: one with the network degraded (tc netem, GET /bench/ping, 50 clients, four profiles) and one with a clean network (payload sizes, echo upload, and 10, 50, or 100 clients). Each cell was summarized by the median and the interquartile range, and HTTP/2 was compared with HTTP/3, in the same condition, with the Mann-Whitney test and Cliff's delta. The median failure rate is zero in every cell. On the 1 MB GET, HTTP/2 had a lower p95 than HTTP/3 in every replicate and a higher request rate in every replicate. On the 100 KB GET, HTTP/2 also had a lower p95 than HTTP/3 in every replicate. On the 100 KB POST, HTTP/3 had a lower p95 than HTTP/2 and a higher request rate in every replicate. On /bench/ping with 50 and 100 clients, and on the undegraded control, the test stays above 0.05. With a 100 ms delay, the three protocols have a median p95 between 102.7 ms and 102.9 ms and a median rate of 494 req/s. These results describe this setup, on one machine, on localhost. The proxy integration required no application code changes. Alt-Svc negotiation and protocol fallback were not tested. The code is open and the collection scripts at \url{https://github.com/mendeslian/QUICBench-Node} allow others to replicate and extend the tests.

\noindent\textbf{Key-words:} HTTP/3. QUIC. Node.js. REST APIs. Feasibility. Performance.
